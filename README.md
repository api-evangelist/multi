> **No longer operating.** This company or product has shut down, been discontinued, or been deprecated. This profile is kept as a historical record and is not maintained or rated.

Multi (originally launched as Remotion in 2019) was a macOS-native multiplayer collaboration application for software teams, offering multi-person screensharing for up to ten participants, shared cursor and keyboard control with sub-100ms latency, session recording, and AI-generated summaries and action items. Backed by Greylock and First Round Capital, the company was acqui-hired by OpenAI in June 2024; the product was shut down and user data deleted, with the founding team joining OpenAI's ChatGPT desktop group. The multi.app site remains live as a static marketing page but exposes no public developer API, SDK, or documentation surface.
